# Olis iOS Widget 0.4 Scene — image loader fix

Исправлено отображение PNG в виджете.

Что изменено:
- `Image("...")` заменён на явную загрузку PNG из `Bundle.main`;
- загрузчик проверяет и корень widget bundle, и подпапку `Resources`;
- добавлен fallback с именем отсутствующего файла вместо пустого места;
- GitHub Actions дополнительно выводит список PNG, реально попавших в `OlisWidget.appex`;
- layout 0.4 не менялся.

Если после сборки картинка не найдётся, на виджете теперь будет видно имя конкретного отсутствующего файла, а не просто пустота.
